# Fugue Content Site

Starter site on the public Fugue stack (`@altafusion/*` on npm): Nuxt 4, Nuxt UI, Nuxt Content, Nuxt Studio. Read `README.md`
for setup, theming and routing.

## Commands

```sh
pnpm dev
pnpm lint && pnpm typecheck && pnpm test && pnpm build
```

Run lint, typecheck and tests on the touched area before calling work done.

## Rules

Cursor loads `.cursor/rules/` natively; Claude Code imports them here so both tools follow the same source.
